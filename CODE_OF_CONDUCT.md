# Code of Conduct

## Our commitment

We want participation in j-api-proxy to be respectful, constructive, and welcoming for everyone. Contributors, maintainers, and community members are expected to help create an environment where people can collaborate without harassment, intimidation, or exclusion.

## Expected behavior

Examples of positive behavior include:

- being respectful in disagreements
- giving and receiving feedback in good faith
- focusing on what is best for the project and community
- showing empathy toward other community members
- using welcoming and professional language

## Unacceptable behavior

Examples of unacceptable behavior include:

- harassment, threats, or personal attacks
- insulting, demeaning, or discriminatory language
- trolling, deliberate disruption, or bad-faith engagement
- publishing someone else's private information without permission
- any other conduct that a reasonable person would consider inappropriate in a professional open source community

## Scope

This Code of Conduct applies in project spaces and in public spaces when an individual is representing the project, including issues, pull requests, discussions, and other related community interactions.

## Reporting concerns

If you experience or witness unacceptable behavior, please report it to the project maintainer through a private GitHub contact path or another private channel available from the maintainer's GitHub profile. Please include relevant details so the report can be reviewed fairly.

## Enforcement

The project maintainer is responsible for interpreting and enforcing this Code of Conduct and may take any action considered appropriate in response to behavior that violates it, including warning, editing or removing content, rejecting participation in project spaces, or banning a participant.

## Enforcement principles

When reviewing reports, the maintainer will aim to:

- protect the reporting party where possible
- review the context carefully and fairly
- respond in a proportionate way
- prioritize community safety and project health
